One-time setup on this device

Uploading saves files straight into the site's GitHub repository, so this page needs a GitHub access token. It is stored only in this browser, never in the site.

  1. Open GitHub → new fine-grained token.
  2. Name it e.g. "Zappy upload", set an expiry (up to a year), and under Repository access choose Only select repositories → this site's repository.
  3. Under Permissions → Repository permissions set Contents: Read and write and Actions: Read-only.
  4. Generate it, copy it, and paste it below.

No token? You can also upload on github.com: open the repository's uploads folder → Add file → Upload files. The site processes them the same way.
